# Anime

The anime library stores anime titles, seasons, episode progress, metadata, artwork, ratings, and other user-specific information.

## AniList import

You can import a public AniList anime list into your anime library. The import is read-only with respect to AniList and can be run automatically on a per-user schedule.

See the [AniList Import guide](anilist.md) for configuration, supported schedule options, update behavior, and scheduling details.

## Editing

Add and Edit use the shared tabbed dialog described in [Media libraries](media-libraries.md#the-add-and-edit-dialogs). The Details tab also holds the anime's format (TV, Movie, OVA…) and its AniList and MAL scores; seasons and episode progress stay on the anime's page.
## Trash

Deleting an entry moves it to trash. Restore returns it with its seasons and episodes;
purge permanently removes it. You can also empty the whole anime trash or have trashed
entries deleted automatically after a period you choose (never by default); see
[Trash, Empty trash and automatic deletion](media-libraries.md#trash-empty-trash-and-automatic-deletion).

## Library features shared with TV shows and anime

Ranks, clickable genres, local pictures and the Add and Edit dialog work the same way here. See
[Movie, TV and Anime Libraries](media-libraries.md). Lists are described in
[Collections and Lists](collections-and-lists.md).
